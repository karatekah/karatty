# Segnalare una vulnerabilità

[English](../../../SECURITY.md) · [Español](../../es/project/SECURITY.md) · **Italiano**

La versione supportata è **v0.1.0-alpha.1**, sperimentale. Usa E2EE locale nelle chat dirette 1:1 e dispone di [test documentati](../verification.md), ma non di un audit indipendente. Il prototipo a inviti e la TUI SSH remota espongono testo leggibile al server e sono esclusi dall'alpha.

Invia la segnalazione privata con **[Security → Report a vulnerability](https://github.com/karatekah/karatty/security/advisories/new)**. Non inserire dettagli sfruttabili, chiavi, token o conversazioni in issue o discussioni. Se manca il pulsante, apri un issue senza dettagli tecnici per avvisare: il canale privato va reso disponibile prima di richiedere informazioni sensibili.

Indica versione/commit, piattaforma, riproduzione e impatto osservato usando dati di prova. Il manutentore confermerà la ricezione e coordinerà correzione/divulgazione con chi segnala. Durante l'alpha non è promesso un tempo fisso di risposta.

Non esistono versioni stabili o precedenti versioni pubbliche che ricevano patch. Applica gli aggiornamenti di sicurezza dell'alpha e consulta le note di compatibilità. Il progetto distribuisce software: non offre ancora hosting o una casella pubblica di supporto.
