La clave SSH acredita el acceso. La frase secreta local protege el archivo de mensajes. El código de recuperación permite sustituir una clave SSH perdida, pero no descifra un archivo local cuya frase se haya perdido ni restaura mensajes que nunca se habían descifrado en el dispositivo.

Las personas deben comparar sus huellas por otro medio antes de verificar el contacto y repetir la comparación si cambia la identidad. El cifrado no protege un dispositivo comprometido, una copia desbloqueada o los metadatos necesarios para entregar mensajes. Usar un seudónimo no garantiza anonimato absoluto.
