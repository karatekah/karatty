# Karatty v0.1.0-alpha.1

[English](../../releases/v0.1.0-alpha.1.md) · **Español** · [Italiano](../../it/releases/v0.1.0-alpha.1.md)

Primera **alpha experimental para uso local**: TUI instalada, directos 1:1 con aceptación y E2EE. Requiere servidor y PostgreSQL propios; no existe servicio de Internet alojado por el proyecto. No necesitas comprar dominio/VPS ni correo de cuenta para probarla localmente.

Compara SHA-256 con [SHA256SUMS](https://github.com/karatekah/karatty/releases/download/v0.1.0-alpha.1/SHA256SUMS). Conserva `karatty` y `karatty-crypto` juntos. Los paquetes incluyen licencias, locks y `BUILD_INFO`; el servidor se compila aparte. No contienen claves ni configuración privada. No están firmados ni notarizados.

## Contenido

- Registro seudónimo con clave SSH Ed25519, sin correo/nombre real, y recuperación mediante código offline.
- Solicitudes y aceptación de directos, rechazo/bloqueo y un dispositivo por cuenta.
- Olm/vodozemac 0.11.1, comparación de huellas por otro canal y nueva verificación al cambiar la identidad.
- Archivo con frase secreta local, Argon2id/XChaCha20-Poly1305, cola persistida y reintentos con el mismo sobre tras reiniciar.
- Sobres opacos en PostgreSQL, secuencias, retención/deduplicación de 30 días y eliminación de cuenta/archivos locales.

## Pruebas y procedencia

Código de etiqueta/paquetes: `5e4adde5e618f5430be7eaedb7f3cba574e666f7`. [CI main](https://github.com/karatekah/karatty/actions/runs/41388516727) y [CI de etiqueta](https://github.com/karatekah/karatty/actions/runs/41389398255) comprobaron PostgreSQL real, E2EE/recuperación, dos TUI Linux PTY, carreras, Go/Rust, paquetes extraídos en tres sistemas y dependencias.

La prueba Windows usó `4c0356f`: dos TUI nativas verificaron huellas, intercambiaron mensajes en ambos sentidos y reabrieron el historial; base y logs no contenían el texto legible de prueba. Hasta el commit publicado, los cambios posteriores eran documentales. La [verificación](../verification.md) identifica la compilación exacta y sus límites.

El cambio posterior del repositorio/módulo y las traducciones no sustituyen binarios ni checksums ni mueven la etiqueta. El código histórico conserva el identificador anterior del módulo.

## Límites conocidos

- **Defender:** clasificó una compilación del servidor como `Behavior:Win32/DefenseEvasion.A!ml`. Funcionó después de que el propietario la restaurara de cuarentena, con protección activa. No se ha confirmado falso positivo ni validado otras instalaciones. No desactives la protección para instalar.
- **LAN experimental:** hay configuración TLS con SAN IP; falta comprobar el chat entre dos equipos físicos.
- **Sin auditoría independiente de Karatty.** El servidor conoce metadatos y puede denegar servicio; seudonimia no es anonimato absoluto.
- El secreto futuro excluye copias antiguas del estado y equipos desbloqueados/comprometidos. Recuperar cuenta no reconstruye archivos/frases perdidos ni mensajes nunca descifrados.
- Archivo de 16 MiB, pantalla de 500 mensajes, lista de 100 conversaciones. El cliente limpia al usarse. No hay respaldos automáticos configurados; cada administrador informa y comprueba su política.
- Grupos, adjuntos, múltiples dispositivos y SSH remoto fuera de alcance. Las invitaciones heredadas guardan texto legible y no son E2EE.
